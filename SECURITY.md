# Reporting a security concern

Email **founder@kritaqo.com** with a short description, the affected Kritaqo version and steps to reproduce using non-sensitive data.

Please do not post an exploitable security issue, passwords, API keys, authentication files or private user data in a public GitHub issue. We do not need your complete installation data folder.

Kritaqo is an early alpha. No independent security audit report has been published, and the installer does not yet have an Authenticode publisher certificate. There is no bug bounty or guaranteed response time.

[How accounts and data are handled](https://kritaqo.com/#trust).
